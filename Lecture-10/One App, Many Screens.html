Stop 5 · The idea

Screens are a stack of cards

1Opening a screen pushes a new card on top.
2Going back pops the top card off. The one below is still there, exactly as you left it.
3You always see the top card.
4The stack is the history. The navigator keeps it, so we don't need useState for it.

Stop 10 · Moving around

Push, pop, jump: try every method

navigate(name)Go to a screen. If you're already on it, just update its params.
push(name)Always add a new card, even of the same screen.
goBack()Pop the top card.
popTo(name)Pop back to an earlier screen with that name.
popToTop()Pop everything down to the first screen.
replace(name)Swap the top card. No way back to it.
// App.js
<Stack.Screen name="Profile" component={ProfileScreen} />
// ChatScreen.js
<Button title="View profile"
  onPress={() => navigation.navigate('Profile', { chatId })} />

Stop 11 · Tabs in code

Move the stack inside a tab

$ npx expo install @react-navigation/bottom-tabs
const Tab = createBottomTabNavigator();
const Stack = createNativeStackNavigator();

function ChatsStack() {
  return (
    <Stack.Navigator>
      <Stack.Screen name="Chats" component={ChatListScreen} />
      <Stack.Screen name="Chat" component={ChatScreen} />
      <Stack.Screen name="Profile" component={ProfileScreen} />
    </Stack.Navigator>
  );
}

export default function App() {
  return (
    <NavigationContainer>
      <Tab.Navigator>
        <Tab.Screen
          name="ChatsTab"
          component={ChatsStack}
          options={{ title: 'Chats', headerShown: false }}
        />
        <Tab.Screen name="Settings" component={SettingsScreen} />
      </Tab.Navigator>
    </NavigationContainer>
  );
}
